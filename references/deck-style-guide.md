# 科研汇报 PPT 风格指南（从用户参考稿学习固化）

关键词：深紫文献解读风、编号徽章、结论式标题、证据卡、已有/待证、页底总结条。

## 色板（默认主题）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 深紫 | `#7D2E68` | 标题栏、卡标签、强调关键词、总结条文字 |
| 辅色 浅紫 | `#F3E8F2` | 卡底结论条、页底总结条底色 |
| 正文 黑 | `#1A1A1A` | 导语、已有句 |
| 卡片描边 | `#C9C9C9` | 白底证据卡细边框 |
| 页面底 | 白 | 全稿白底 |

## 页型与版式

### evidence（证据页，主力页型）
1. **页首**：通栏深紫圆角标题栏（高约0.78"），左端白描边圆形徽章内白色两位数编号（02/04/08…），右侧白色加粗主题词（递送策略/迁移证据/急性疗效）。
2. **导语**：标题栏下一句黑体加粗核心结论（浅灰底条），关键词用主色强调，如"通道成像""正交定位"。
3. **主体**：**1–3 张并排证据卡，严禁一图一页**。每卡自上而下：
   - 紫底白字标签条（卡片关键词，如"ICO原位装载""迁移追踪"）；
   - **整幅多子图组合图**（一个 Figure 的多个 panel 合为一卡；子图拆分仅用于分组，组内多 panel 横向拼接）；
   - 浅紫底结论条（主色加粗短句，如"第14–28天：脑萎缩减轻"）。
4. **页底总结条**：浅紫通栏，主色加粗；内容为流程式（"装载 → 迁移 → 定位 → 治疗"）、样本量口径（"脑体积n=3–7/组；运动行为n=14–16/组"）或限定结论（"支持髓系细胞参与；具体转移路径仍待直接追踪"）。

### limitations（局限页）
- 同样的深紫标题栏+编号徽章。
- 纵向 2–4 行：左端**箭头形（PENTAGON）紫底白字标签**（来源与路径/颗粒与药物/临床外推），右侧白底细边框行内两行对仗：
  - `已有：…`（黑色加粗，已确认事实）
  - `待证：…`（主色加粗，待验证事项）

### 文字规律
- 标题带结论与数字："24小时TTC：梗死体积降低26.7%"，不写"结果展示"这类空题。
- 每卡一句结论，量化优先（百分比、n、时间点）。
- 区分事实与待证：已有/待证、支持/仍待、未量化 等限定词保留，不得把待证写成已证。
- 样本量口径放页底总结条，不挤进图注。

## outline JSON 页型示例

```json
{"type":"evidence","number":"04","title":"迁移证据",
 "lead":"先看Sham与LPS通道成像，再看血管周围空间正交定位",
 "cards":[
   {"label":"微通道成像","image":"fig1.png","caption":"LPS组Gr1信号更密集"},
   {"label":"血管周围空间","image":"fig2.png","caption":"可见载颗粒细胞"},
   {"label":"硬脑膜","image":"fig3.png","caption":"颗粒与Gr1细胞共定位"}],

```

## 与子图拆分的关系

`split_panels.py` 拆出的 A/B/C/D 面板**用于分组进卡**：
- 每页 ≤3 卡；panel 均分到卡，组内多 panel 用 `_hstack_images` 横向拼接为一张组合图；
- 助手写 outline 时应按**语义**分组（同一论证的 panel 进同一卡），并给每卡提炼关键词标签与结论条；
- 离线兜底仅按顺序均分，标签/结论留待提炼占位。
